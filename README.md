# Student Registration System

## Project Description

This is a PHP and MySQL based Student Registration System.
It allows users to add, display, update, delete and search student records.

## Features

- Add Student
- Display Students
- Update Student
- Delete Student
- Search Student
- Student Status Management
- Pending / Approved Status

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- PDO
- XAMPP
- phpMyAdmin

## Database

Database Name:

student_registration

Table Name:

student

## Student Table

| Field | Description |
|---|---|
| STD_ID | Student ID |
| NAME | Student Name |
| ROLLNO | Student Roll Number |
| PHONE | Student Phone |
| DEPARTMENT | Student Department |
| DOB | Date of Birth |
| STATUS | Pending or Approved |

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Create the `student_registration` database in phpMyAdmin.
4. Create the `student` table.
5. Put the project folder inside `htdocs`.
6. Open the project in the browser.

Example:

http://localhost/SRS/SRS.php

## Status System

New students are registered with:

PENDING

The status can later be changed to:

APPROVED
